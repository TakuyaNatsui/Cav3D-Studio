# Cav3D Studio — 3 次元の高周波空洞・導波管の解析ソフト（試用版）

[English](README.md)

Cav3D Studio は、高周波の空洞共振器や導波管部品を設計するための Windows 用デスクトップアプリです。
内蔵の 3D CAD で形を作り、材料と境界条件を割り当てて、共振モード・Q 値・S パラメータ・電磁場を
同じ画面で計算できます。

計算には **曲線四面体上の 2 次 Nédélec 要素（辺要素）** を使っており、少ない要素数で高い精度が出ます
（例: ピルボックス空洞の TM010 モードは、約 1,300 要素で解析解と 0.1 % 以内で一致）。

このリポジトリは Cav3D Studio の **配布（ダウンロード）・文書・問い合わせ（Issues）** の場所です。
アプリのソースコードは含みません。

> **試用版:** すべての機能を使えますが、解析できるのは **要素数（四面体の数）が 10,000 以下のメッシュ**
> だけです。[試用版の制限](#試用版の制限) を参照してください。

## できること

- **3D CAD**: 拘束と寸法つきのスケッチ、押し出し、回転、ブーリアン、フィレット・面取り、ミラー、パラメータ。
  STEP / IGES / BREP の取り込み
- **物理**: 領域ごとの材料（εr、μr、誘電正接 tanδ）、境界条件（PEC、電気壁 E-short、対称面用の磁気壁 M-short、
  ウェーブポート）
- **メッシュ**: 曲線の 2 次四面体メッシュ。統計と要素品質の表示
- **固有モード解析**: 共振周波数、電磁場（蓄積エネルギー 1 J に規格化）、壁損失（導電率）と誘電体損失による
  Q 値、ジオメトリファクタ G、損失電力
- **ポートスイープ（S パラメータ）**: 任意の断面の導波管ポートと同軸（TEM）ポート（特性インピーダンスを表示）。
  S パラメータを基準インピーダンス（50 Ω など）に換算できる。適応スイープ、任意の周波数の場のスナップショット
- **1 ポート空洞の共振探索**（カプラーなど）: 共振周波数 f0、外部 Q（Qe）、内部 Q（Q0）、負荷 Q（QL）、結合度 β
- **表示**: 断面・全要素の矢印とカラーマップ、2D 断面図、金属壁の電場・磁場・表面電流、S パラメータの図
- **書き出し**: CSV、VTK（ParaView）、Touchstone（.sNp）、規則格子のフィールドマップ（HDF5 / CSV。ビーム計算向け）。
  結果はプロジェクトに HDF5 で保存
- **コマンドライン**: 同じ EXE で GUI を使わずに解析できる（`Cav3D-Studio.exe --help`）
- 画面は日本語と英語

## ダウンロードと起動

1. [Releases](https://github.com/TakuyaNatsui/Cav3D-Studio/releases) から `Cav3D-Studio-<版>-trial-win64.zip` をダウンロードします。
2. （任意）`SHA256SUMS.txt` の値でファイルを確かめます:
   `certutil -hashfile Cav3D-Studio-<版>-trial-win64.zip SHA256`
3. zip をローカルのフォルダ（例: `C:\Cav3D-Studio`）に展開します。ファイル数が多いので、クラウドで同期される
   フォルダ（OneDrive、Dropbox など）は避けてください。
4. 展開したフォルダの `Cav3D-Studio.exe` を実行します。

EXE にはまだ **コード署名がありません**。「Windows によって PC が保護されました」と出たら、配布元を確かめたうえで
**詳細情報** → **実行** を押してください。公開直後の EXE はウイルス対策ソフトに誤って検出されることがあります。
その場合は [Issues](https://github.com/TakuyaNatsui/Cav3D-Studio/issues) でお知らせください。

版と構成の確認: コマンドプロンプトで `Cav3D-Studio.exe version`。

## 試用版の制限

- 解析（固有モード、ポートスイープ、場のスナップショット、共振探索、コマンドラインの `run-cavity` / `run-driven`）が
  できるのは、**要素数 10,000 以下のメッシュ** だけです。それより大きいメッシュも生成と確認はでき、解析は計算を始める
  前にメッセージを出して止まります。メッシュサイズを大きくして要素を減らしてください。
- それ以外の機能（モデリング、メッシュ生成、結果の表示と書き出し）は製品版と同じです。
- 用途の制限はありません（業務・営利目的にも使えます）。
